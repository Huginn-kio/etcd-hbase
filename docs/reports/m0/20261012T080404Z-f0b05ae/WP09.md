# WP09 执行报告

关联任务：固定 etcd v3.5.23 proto 来源与 Java/gRPC 生成。协议源基线为上游 tag `v3.5.23`，commit `1cf4bc40111fd95d1e14a90a09a146357b15eb13`。`rpc.proto`、`kv.proto`、`auth.proto` 按原始内容保存；Gogo 与 Google API 导入源分别固定到 `v1.3.2` 和锁定 commit。来源路径、revision、许可与 SHA-256 记录在 `protocol/proto-sources.lock.json`。

Maven `protocol` 模块通过锁定的 protobuf-maven-plugin 生成 protobuf 消息与 gRPC Java 服务绑定。protoc 4.36.2、protobuf-java 4.36.2、protoc-gen-grpc-java 1.84.1 和 Java 注解 API 的版本/摘要已登记；生成物只位于忽略的 `target/generated-sources/`。

验证：

- `python3 scripts/verify/m0-protocol.py` 通过，核对 6 个 proto 文件的 SHA-256、etcd commit、工具版本和 Maven 激活配置。
- `scripts/dev/mvn21.sh -ntp -pl protocol -am clean verify` 在 Temurin 21 下通过，生成并编译 18 个 Java 源文件。
- `scripts/dev/mvn21.sh -ntp clean verify` 全 9 个 reactor 项目通过，4/4 descriptor/wire 测试无失败、错误或跳过。
- 连续两次 clean 构建的 18 个生成 Java 文件逐字节一致；protoc 与 gRPC 生成器从 Maven Central 获取的 macOS arm64 二进制摘要与依赖锁匹配。
- POM、JSON、`git diff --check` 通过。

边界：没有连接真实 etcd 或 HBase；Go/Java 互通在后续 WP11/WP21 验证。协议生成不实现服务业务，也不宣称 M0 目标环境验收通过。
