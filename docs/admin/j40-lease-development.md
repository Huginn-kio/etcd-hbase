# J40 Lease 开发配置

启用 `m4_lease_api_enabled` 时，`memory_bytes` 必须覆盖每个表组常驻的恢复账户，以及同一次 Lease 请求的 gateway 和 owner 账户。启动时根据表组数量和 `max_etcd_request_bytes` 校验该下限，配置不足会明确拒绝启动。

当前预留中每个恢复账户为 60,948,480 字节；owner 账户为 151,126,016 字节；gateway 账户按带 keys 的 TTL 请求计算，为 151,060,480 字节加上 `max(65,536, 3 × (max_etcd_request_bytes + 65,536) + 32,768)` 字节。以示例的 1,572,864 字节请求上限为例，单表组最低为 368,082,944 字节，每增加一个表组需再加 60,948,480 字节。

该下限只保证空闲账本有足够预留准入一组请求与 owner；并发请求、其他工作负载及实际部署仍需额外预算。账本不是 JVM 或 HBase client 的完整内存上限，目标环境的容量和身份验收仍需单独完成。
